# Felix Eisenhuth Web Dev

Statischer Portfolio-Prototyp für Felix Eisenhuth: Webdesign, Frontend-Entwicklung, Logo- und Printdesign.

## Lokal starten

Im Projektordner:

```bash
python3 -m http.server 8080
```

Danach http://localhost:8080 öffnen. Es gibt keinen Build-Schritt und keine Node-Abhängigkeiten.

## Aufbau

- `index.html`: Seitenstruktur und Scrollsequenz
- `additions.css`, `work-motion.css`, `contact.css`: Layout und Animationen
- `preloader.js`, `smooth-scroll.js`, `logo-morph.js`: interaktive Effekte
- `frames/`: aktive Schwarzweiß-Portraitsequenz aus 72 Bildern
- `assets/`: Logo, Schriften, Grain und Markenlogos inklusive vorhandener Schriftlizenzen

Die Work-Karten enthalten illustrative Demo-Projekte. Der Kontakt-CTA öffnet das Mailprogramm. Es gibt kein Formular-Backend.
